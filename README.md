# Social Media Automation

A Python-based application for creating, scheduling, and automatically publishing social media posts.

## Features

- Create and manage posts
- Schedule posts
- Automatic post publishing
- Track post status
- Record publishing time
- Demo mode for testing

## Technologies

- Python
- Requests
- Python-dotenv
- Schedule
- JSON

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt

Run the application:

python main.py

Run the scheduler:

python scheduler.py

## Note:

The current version uses Demo Mode to simulate social media publishing without requiring real social media credentials.
